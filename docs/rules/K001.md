# K001 — No rules declared

**Severity:** warning
**Category:** Completeness

## What this catches

An agent document where `agent.rules` is empty. Either the author forgot
to write any rules, or the file is using the wrong artifact type (a RAG
manifest, a skill description, …) and was linted with `--target claude_code`
by mistake.

## Why it matters

The whole point of `[[rules]]` is to give the LLM operational guidance.
A context file with sections for `identity` and `stack` but no rules
ships prose the model reads once and forgets — there is nothing to
enforce, nothing to remind the model of mid-session.

## Suggested fix

Add at least one rule:

```toml
[[rules]]
id = "TDD-001"
title = "Write a failing test before any production code change"
severity = "must"
rationale = "Catches regressions before the PR review hits them."
```

If the file is intentionally rule-free (a pure introduction document,
say), consider:

- Moving it out of `.ctx` and into prose under `docs/`.
- Setting `artifacts = []` so the lint target doesn't expect rules.

## When to silence

If the document is genuinely a stub (a brand-new `.ctx` you have not
filled in yet), K001 flags exactly that. Silencing it would mean
ignoring the gap; the better fix is to write the first rule.
